# Yet the Butterflies Flutter Away
> *"The deeper the love, the greater the betrayal."*

An interactive psychological drama, dark fantasy, and tragedy web visual novel.

## 📖 Story Overview
General Joan, celebrated military hero of the realm, returns to his estate and his beloved noble wife, Lady Aflania. But behind the serene palace walls lurks Lieutenant Laqquo, a cunning subordinate harboring unspoken resentments and poisoned whispers. 

Every choice shifts General Joan's paranoia level, leading to one of five distinct dramatic endings (Endings A, B, C, D, and E) and an introspective Epilogue.

---

## ✨ Features
- **Authentic DDLC & Cinders First-Person POV Aesthetic**: Clean bust-up character framing facing the camera, animated idle breathing, atmospheric Vignette, and responsive dialogue interface.
- **5 Multi-Branching Endings & Cinematic Video Revelations**:
  - **Ending A**: *The Truth Exposed* — A Chance to Begin Again
  - **Ending B**: *A Fragile Peace* — The Lie Survives in Silence
  - **Ending C**: *The Marriage Destroyed* — Jealousy Wins Without a Sword
  - **Ending D**: *The Price of Forgiveness* — Love Does Not Guarantee Reconciliation
  - **Ending E**: *The Solitary General* — A Life Lived in the Shadow of Doubt
- **Full Epilogue & Theatrical Film Credit Scene**: Featuring the complete 11-member production team.
- **Full Device Responsiveness**: Optimized for desktop, laptops, tablets, and smartphones (portrait & landscape) with iOS safe area notch/home bar support.
- **Save & Load System**: 6 persistent timeline save slots + auto-save powered by browser `localStorage`.
- **Audio Synthesizer & Video Soundtracks**: Dynamic sound effects, music levels, and mute toggles.

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/noven24/Yet-the-butterflies-flutter-away.git

# Navigate to project directory
cd Yet-the-butterflies-flutter-away

# Start the local server
npm start
# or: node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
